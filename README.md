# ウィジェットメモ

Android 8.0以上向けのJava / Android Viewsによるネイティブメモアプリ。WebViewは使用していません。

## 機能
- メモの作成、編集、削除。日本語、改行、絵文字に対応。
- 小（2×1）、中（2×2）、大（4×3）のホーム画面ウィジェット。
- ウィジェットを長押しして縦横のサイズを変更（サイズ・操作はランチャーに依存）。
- ウィジェットをタップして編集画面を開き、保存すると反映。
- 複数のメモを別々のウィジェットに設定。同じメモを複数に表示することも可能。
- メモは端末内に保存。通信権限、アカウント、広告なし。ウィジェットを削除してもメモは保持。
- 自動保存ではなく明示的な保存。キャンセルで変更を破棄。アプリをアンインストールするとデータは削除。

## インストール
GitHubのReleasesにある `kotsukotsu-memo.apk` をAndroid端末で開いてインストールします。ZIPの展開は不要です。
アプリでメモを作成後、ウィジェット追加ボタンからサイズを選ぶか、ホーム画面のウィジェット一覧から追加してください。
初回配置後にウィジェットをタップして新しいメモを書く、または既存のメモを選択してください。

## ビルド
JDK 17、Gradle 8.11.1、Android SDK platform 35 / build-tools 35.0.0を使用。
Android Studioでこのフォルダを開くか、SDKを設定して以下を実行してください。

```sh
gradle :app:assembleDebug :app:lintDebug
```

出力: `app/build/outputs/apk/debug/app-debug.apk`
Gradle Wrapperは同梱していません。上記バージョンのGradleをインストールしてください。
GitHub Actionsはpush時にビルドとlintを実行し、成功時にAPKをReleaseへ直接添付します。
Actionsが無効なリポジトリでは有効化が必要です。
デバッグ署名はCI実行環境ごとに変わるため、後続ビルドを上書きインストールできない場合があります。継続配布には固定のリリース署名鍵を設定してください。

## 検証状況
ソースのXML整合性、3種類のサイズ設定、Java全ソースとAndroidリソースのコンパイルを確認済み。APK生成・lintの実行結果はGitHub Actionsを参照してください。実機・エミュレータでの動作確認は未実施です。
Actions成功後も、実機で以下を確認してください。
1. メモ保存→アプリ再起動で保持、編集、キャンセル、削除。
2. 小・中・大の追加、縦横サイズ変更、各ウィジェットから別メモの編集。
3. 同一メモを表示する複数ウィジェットの更新、削除後の再設定。
4. 日本語入力、長文、絵文字、画面回転時の編集中テキスト保持。
5. ホームアプリ/端末再起動で表示保持、ウィジェットだけ削除してもメモ保持。
